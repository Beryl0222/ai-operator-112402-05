# 移动端神经纹理的可微哈希网格与局部贴图替换

这里的分层空间网格和纹理视窗是用于设备联调的合成资料。使用 Node.js 22。运行 `npm ci --offline` 核对依赖锁，`npm run inspect` 查看资料字段，`npm test` 检查资料格式及相互引用。检视脚本只读取元数据。

## 数据格式

尺度 levelResolution 是单轴格数。实际顶点坐标限制在 [0,R]。归一化位置用 R 缩放，1 恰取最后的格的右侧，内部格线的空间导数取向较大坐标的单侧。顶点沿 z,y,x 连续枚举，角点没有发布时被标记 unknown；权重为零则不影响正值，但一侧求导的依存仍按权重导数。slot 对每层分别由 [x,y,z] 给出，低分辨率直接索引，高分辨率按 atlas.mjs 的厂家哈希签名。维度为 4，每层独立，缺角不是 hash 值零。protected 读数和编辑区格点都随资产版本；只有已登记视窗参与本轮保护判断。updateFetchLimit 是变化以后供给方的新视窗请求额度，每次区块交付记一次。memoryBytes 包含局部训练、索引和此次优化保留的工作区。 每视窗含四个三坐标，训练集合和保护集合按视图号的半开范围提供。逐次更新查询由调用方给学习率与稀疏坐标，需返回可复用的梯度及拟议参数变化，保护约束按拟议步前后每个可读视窗分量的 epsilon 判断。 像素中的 4 个采样依其先后作为射线记录，605 的第一个采样是靠近保护区外缘的实际点，不携带槽号。调用方的取数上限同时覆盖因碰撞引发的保护检查。

## 取数

`inputs/atlas.json` 保存标定、规格和调用记录。记录中的范围除明确说明外从零开始，使用半开区间。批量数组按调用记录列出的顺序交付。atlasSlot(level,x,y,z) 是设备资产的坐标码本，atlasView(view) 和 atlasFeature(level,slot,revision) 分别返回视窗和参数。
