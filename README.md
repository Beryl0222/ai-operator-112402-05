# 折叠屏相机的可覆盖区域积分重采样

项目资料使用可独立读写的 JSON。Node.js 22.23.4 下运行 `npm ci --offline` 准备环境，然后运行 `npm run inspect` 检查合成数据字段，运行 `npm test` 校验样本引用及格式。

## 输入契约

所有矩形按半开区间给出 [x0,y0,x1,y1]。源像素为相邻整数坐标边界间的常值线性 RGB，已登记区域按各自的轴对齐仿射变换给目标像素的输入足迹；变换系数顺序为 [sx,sy,tx,ty]，限正尺度。按屏幕目标足迹面积计权，返回覆盖区平均色与 alpha=真实覆盖面积/目标像素面积，覆盖零时颜色缺失。合成差值与面积误差容许 1e-6。片内有样本的有效子矩形按优先级遮挡，相同优先级的重叠输入视为冲突。资源预算计运行时持有的中间数据，不计调用方输入与领取后输出。 empty 由帧报告，直接限制屏幕覆盖，优先于任一片的有效矩形。它不等同于低优先级图上缺值。带标签的面积一律在屏幕空间计量。

## 资料读取

样本位于 `inputs/session.json`，其中 `events` 是按到达顺序记下的操作，编号从零开始。geometry、preview、cover 按几何版本引用，预览和封面还给出目标行。expect 声明后续将读取的片，tile 为片实际到达。empty 给出已声明无源覆盖的版本和屏幕矩形。

## 设备联调资料

正式资料使用 `inputs/qualification.json`，每个相机片有传感器尺寸与当前修订的仿射矩阵 `[a,b,c,d,tx,ty]`，坐标向屏幕映射为 `[a*x+b*y+tx,c*x+d*y+ty]`。各片的 `valid` 是源坐标里的半开矩形。`blocked` 是真实物理遮挡，屏幕空间中优先于所有来源的凸四边形。待到来的高优片其有效坐标范围已知，未到行在范围内是否遮挡未知。相同优先级中覆盖冲突按面积区分，其他面积仍可预览。近似遮挡深度混合不属于设备契约。面积误差和颜色误差使用小图所列上限。屏幕读区 `[x0,y0,x1,y1]` 与格距 `pitch` 形成以请求左上为相位的网格，边缘格裁在读区矩形内。`lines` 提供单片的源图行半开区间，`scope` 绑定目标方及折角修订，`read` 请求对应 scope 的区域。`maxReads` 统计每轮复核中供应方实际取回的整行次数，复读同一行重复计。不限制算子保存少量可回用的积分中间量，`maxWorkBytes` 包含这些中间量和待领输出。
